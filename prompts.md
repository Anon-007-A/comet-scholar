# Comet Scholar — Prompt Library

Below are the primary prompts to run inside Perplexity Comet Browser. Open 5–7 research papers in separate tabs, then use these prompts one by one.

## 1. Enhanced Literature Review Generator
Create a comprehensive academic literature review using the open tabs with this structure:
1. INTRODUCTION (2-3 sentences on the field)
2. METHODOLOGY ANALYSIS (compare research methods, sample sizes, data collection approaches across studies)
3. KEY FINDINGS BY THEME (organize findings with in-text citations as (Author, Year))
4. THEORETICAL FRAMEWORKS (identify and compare theoretical models used)
5. RESEARCH GAPS (list at least five distinct gaps, each with one sentence explaining why)
6. FUTURE RESEARCH DIRECTIONS (3-5 specific research questions)
7. CONCLUSION (synthesis and implications)
Format references in APA style at the end. Use the open tabs as sources and include inline citations.

## 2. APA Reference Formatter
Convert the following raw references into proper APA entries. Ensure: author(s), year, title, journal, volume(issue), pages.
[PASTE RAW REFERENCES HERE]
Eg:Harry J 2023 Role of AI in education  Educational Technology Research 15(3) 45-62
Selwyn, Neil. 2022. Future of AI and Education. European Journal of Education. 57(1): 8–20

## 3. Methodology Data Extractor
From the open tabs, extract: author(s), year, methodology summary, sample size, data sources, strengths, limitations.
Output as CSV with headers: Study, Year, Methodology, Sample Size, Data Sources, Strengths, Limitations.

## 4. Research Gap Identifier
Using the open tabs, list the main research gaps. Provide at least five bullet points; each should have one sentence explaining why it is a gap.

## 5. Future Research Questions Generator
From identified research gaps, generate five specific, actionable research questions. Present each as a complete sentence ending with a question mark.

## 6. Academic Summary Diagram (text)
Create a text diagram that maps research gaps against themes and methodologies. Use bullet points and arrows to show relationships.

---

## Example usage order
1. Run "Methodology Data Extractor" → export CSV  
2. Run "Enhanced Literature Review Generator" → produce structured review  
3. Run "APA Reference Formatter" → produce formatted references  
4. Run "Research Gap Identifier" and "Future Research Questions Generator" → add to review
