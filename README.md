# Comet Scholar

Turn 8 hours of research into 8 minutes — a Comet-based academic research workflow.

## Elevator pitch
Comet Scholar is a prompt-driven workflow for the Perplexity Comet Browser that automates literature reviews: method comparisons, thematic findings, professionally formatted APA references, research gap identification, and future research questions — all in minutes.

## Quick Start (for judges)
1. Install Perplexity Comet Browser: https://perplexity.ai/comet  
2. Open 5–7 research papers in separate Comet tabs.  
3. Open this repo and copy the **TRY IT NOW** prompt from `TRY_IT_NOW.md` (or a specific prompt from `prompts.md`).  
4. Paste the prompt into Comet and run.  
5. Inspect the generated literature review and references. Export to Google Slides / Docs if needed.

## Try it now (one paste test)
1. Open Comet with 3–6 papers in tabs.  
2. Open `TRY_IT_NOW.md` in this repo, copy the full prompt, paste into Comet, and run.  
3. You should get a short structured review (Intro → Methods → Key Findings → References).  
*(This single prompt is designed to demonstrate the core workflow quickly.)*

## Files in this repo
- `prompts.md` — full prompt library and usage notes  
- `TRY_IT_NOW.md` — single ready-to-run test prompt (copy/paste)  
- `demo-script.md` — demo flow for a 4–5 minute Loom video  
- `sample-output.md` — example generated literature review excerpt

## Built with
Perplexity Comet Browser, Prompt Engineering, Google Slides, Markdown
