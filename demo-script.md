# Demo Script — Comet Scholar (Loom / Devpost demo)

Total time: 4–5 minutes

1. Hook (0:20)  
"Ever spent 8 hours on a literature review? What if it took 8 minutes instead?"

2. Setup (0:30)  
Show: Comet Browser with 5–7 papers open in tabs. Mention quick-start steps from README.

3. Run Methodology Data Extractor (0:40)  
Show CSV output for methods/samples — emphasize speed and structured data.

4. Run Enhanced Literature Review Generator (1:10)  
Paste prompt, run, show structured output (Intro → Methods → Findings → Gaps → Future Work).

5. Run APA Reference Formatter (0:30)  
Show formatted references section.

6. Show Research Gaps + Future Questions (0:30)  
Highlight 3 clear gaps and 3 research questions produced.

7. Results & CTA (0:30)  
"Produced a publication-ready review in minutes. Download prompts on GitHub and try it in Comet."
